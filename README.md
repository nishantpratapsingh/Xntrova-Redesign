# Xntrova Technologies – Homepage Redesign

A modern, responsive homepage redesign created as part of the Web Developer practical assessment for Xntrova Technologies.

The project focuses on improving the website's visual hierarchy, user experience, responsiveness, conversion flow and interactive elements while maintaining a professional digital agency identity.

---

## Project Overview

The objective of this project was to redesign and develop a modern homepage for a digital marketing and technology agency.

The homepage is designed to communicate the company's services, value proposition, process and credibility while providing clear calls-to-action for potential clients.

The design follows a clean, modern and minimal visual approach with an emphasis on usability and conversion.

---

## Homepage Sections

The redesigned homepage includes:

1. Header / Navigation
2. Hero Section
3. About Xntrova
4. Services
5. Why Choose Us
6. Process / How We Work
7. Portfolio / Case Studies
8. Client Testimonials
9. Call-to-Action
10. Contact / Lead Form
11. Footer

---

## Key Features

- Responsive desktop, tablet and mobile layouts
- Responsive mobile navigation menu
- Smooth scrolling navigation
- Interactive service cards
- Hover effects and transitions
- Portfolio / case study section
- Interactive testimonial slider
- Automatic testimonial rotation
- Contact / lead generation form
- Front-end form validation
- Scroll-based reveal animations
- Back-to-top navigation
- Semantic HTML structure
- SEO-friendly heading hierarchy
- Accessibility considerations
- Lightweight implementation
- No unnecessary JavaScript frameworks or libraries

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

No frontend framework was used because the homepage could be implemented efficiently with lightweight vanilla HTML, CSS and JavaScript.
